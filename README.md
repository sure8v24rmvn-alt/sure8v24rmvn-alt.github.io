# 个人主页 · 使用说明

**线上地址：https://sure8v24rmvn-alt.github.io/**
仓库：https://github.com/sure8v24rmvn-alt/sure8v24rmvn-alt.github.io（GitHub Pages，main 分支根目录）

一个「个人介绍 + 简历 + 作品集」三合一的单页网站。原生 HTML / CSS / JavaScript 手写，
**没有任何依赖、不需要安装任何东西、不需要联网**，双击 `index.html` 就能看。

## 改完怎么发布

```bash
git add -A && git commit -m "改了什么" && git push
```

GitHub Pages 会在 1–2 分钟内自动重新发布，地址不变。国内直连 github.com 的 git 操作需要开代理；`api.github.com` 和 `*.github.io` 一般可以直连。

## 一、30 秒上手

1. 双击 `index.html`（或右键 → 打开方式 → 浏览器）。
2. 想改内容 → 打开 `js/data.js`，改完存盘，回浏览器按 `Ctrl + F5` 刷新。
3. 改坏了不要慌：把改错的那一行前面加 `//` 注释掉，页面就能重新打开。

> 建议用 **VS Code** 打开整个文件夹改（免费）。它会用颜色帮你标出引号、括号有没有配错，
> 比记事本安全得多。

## 二、文件结构

```
个人主页/
├── index.html                页面骨架（一般不用动）
├── css/style.css             全部样式：颜色、字体、间距、动画
├── js/data.js     ★★★★★    所有文字内容都在这里，你只改这一个文件
├── js/app.js                 交互逻辑（一般不用动）
├── js/demo.js                案例页的离线演示（迷你版，可交互）
├── 本地预览.cmd              可选：起一个本地服务器（直接双击 index.html 也能看）
├── assets/
│   ├── cv.pdf                简历 PDF（当前就是最新版）
│   ├── icons/                ← 技能区的软件 logo（SVG，单色，随主题变色）
│   └── images/
│       ├── og-cover.jpg      分享卡 1200×630
│       ├── fieldwork/        返家乡社会实践：主视觉背景板 + 两张海报
│       └── projects/
│           ├── coexistence-chair/   共栖椅：实拍、三视图、加工图、展板
│           ├── ai-kaoyan/           成长计划：界面截图
│           └── tezign-rules/        特赞：规则体系图、测试记录、封面
└── README.md                 本文件
```

技能区的软件 logo 放在 `assets/icons/`，在 `data.js` 的技能条目里用 `logo` 指定：

```js
{ name: 'Figma', logo: 'assets/icons/figma.svg', note: { zh: '界面原型与协作交付' } }
{ name: 'Axure', logo: 'assets/icons/axure.png', note: { zh: '带交互的高保真原型' } }
```

图标都是软件官方的彩色 logo（24px），SVG 和 PNG 都行；暗色模式下会自动加一块纸色底，深色图标不会糊掉。新增软件时把图标放进 `assets/icons/`、补一行 `logo` 就行。PRD / Prompt / AI Workflow 这类不是软件的能力项，用的是自己画的线性图标（`doc.svg` / `prompt.svg` / `loop.svg`）。

## 三、三个最常用的操作

### 1. 改文字
打开 `js/data.js`，按注释逐项替换。文字有两种写法：

```js
title: '我的作品'                          // 只写中文
title: { zh: '我的作品', en: 'My Work' }   // 写双语，右上角"EN"按钮可切换
```

没写 `en` 的地方会自动显示中文，不会变空白。

### 2. 加图片
1. 把图片放进 `assets/images/projects/<作品id>/`，例如 `assets/images/projects/coexistence-chair/hero1.jpg`；
2. 在 `data.js` 里把这个作品的 `cover` 写成该路径：

```js
cover: 'assets/images/projects/coexistence-chair/hero1.jpg',
images: [
  { src: 'assets/images/projects/coexistence-chair/hero2.jpg', caption: { zh: '猫经洞口穿行' } },
],
```

**路径写错或图片不存在也不会出现破图** —— 页面会自动退回一张按作品 `id` 生成的抽象图纸占位图。

图片建议：转成 **WebP**（质量 80% 左右），长边控制在 1600px、单张 ≤250KB。现在全站图片已经从 4.8MB 压到约 2.1MB：
`assets/images/projects/` 下同名 `.webp` 就是页面实际加载的版本，`.jpg` 原件保留着，换图时重新导一份 WebP 即可。

### 3. 换主色 / 换字体
打开 `css/style.css` 最上面那一段 `:root{...}`，改 `--accent` 一个值，整个网站的按钮、
编号、时间线圆点、选中状态会一起变色：

```css
--accent:#A8452B;    /* 现在是砖红。深蓝 #1F4E79、墨绿 #2F5D50、炭黑 #333 都好看 */
```

## 五、作品详情：两种形态

普通作品（写 `desc` / `images`）打开就是「左图右文」的详情页；
如果作品里写了 `board`，详情页会变成**一张重排过的展板**——原展板上的图被切成单块，按 12 栏网格重新排，
文字和图注重写、可选中、手机上单列，而不是把一张 A1 缩到屏幕里让人看不清。

```js
board: {
  no: 'A-01 · 展板重排',        // 图号
  en: 'Coexistence Chair',
  meta: [ { k: '课程', v: '…' } ],   // 标题下的信息表
  panels: [
    { t: 'text',   w: 6, kicker: '01 / 设计说明', h: '标题', body: ['…'], items: ['…'], en: ['…'] },
    { t: 'figure', w: 6, src: 'assets/images/.../hero1.jpg', cap: '图注', note: '1:1 实物' },
    { t: 'list',   w: 6, groups: [ { title: '人类空间特点', items: [['中文','ENGLISH']] } ] },
  ],
  original: 'assets/images/.../board.jpg',   // 原板，页脚给一个"查看原始展板"的链接
}
```

`w` 是占 12 栏里的几栏（12 = 整行，6 = 半行，4 = 三分之一）。想加一块就复制一行改内容。
同一行的几块 `w` 加起来最好等于 12，版面才整齐。

三个可选字段：

- `anchor: true` —— 文字块的清单会落到行底，和旁边大图的底边对齐（正文很短时别加，会中间空一段）
- `original` —— 页脚给一个「查看原始展板」的链接
- 不是展板的产品类作品也能用：把截图当成 `figure` 面板排成流程，一样能讲清楚一个项目

## 六、在线工具与内嵌（embed）

共栖椅的参数化生成工具部署在 NoCode 上（`https://parametric-cat-chair.nocode.host`），
作品详情页标题下有一个「打开设计工具 ↗」按钮，直接指向这个地址。地址写在 `data.js` 的
`projects[0].links` 里，换部署地址只改这一处。

想在页面里**内嵌**一个外部应用，用 `embed` 面板：

```js
{ t: 'embed', w: 4, src: 'https://parametric-cat-chair.nocode.host',
  title: '参数化设计工具', cap: '在线工具 · 可操作' }
```

- `embed` 默认按手机比例（390:844）显示，适合成长计划这类移动端应用；
  桌面尺寸的 3D 工具建议用按钮新窗口打开，塞进面板会很难用。
- 本地双击 `index.html` 时，浏览器禁止内嵌本地页面，那一格会显示一句说明；部署到线上就正常。
- 外站必须允许被 iframe（响应头里没有 `X-Frame-Options: DENY`）。

### 隐私开关

`profile.showPhone` 默认是 `true`，手机号会显示在联系区。不想公开就改成 `false`，
联系区只留邮箱，其他位置不受影响。

## 七、演示（js/demo.js，离线可用）

案例页标题下「打开演示 →」打开的是**按原版 UI 复刻的静态版**——米黄底、小绿人、390px 手机壳、
底部四项导航、三段式 AI 卡，颜色和圆角都取自原项目源码（`--bg:#f7f2ea` `--primary:#7d9b76` …），
小树苗和导航图标是原版 SVG 原样搬运。

五个屏：落地页 → 目标 → 路线 → 日历 → 今日 → 复盘。交互是真的：

- 改「每日可用小时」→ 路线页说明和今日建议跟着变
- 勾任务 → 完成率变化 → AI 建议换分支（负荷超载 / 完成率不足 / 节奏正常）
- 点「采纳」→ 计划真的被改（删任务 / 拆时长 / 调总量），建议再变
- 复盘选「学不会 / 没时间 / 没动力 / 临时有事 / 身体状态不好」→ 各走不同建议

纯前端、一个文件、不联网、不需要服务器；状态存 `localStorage`（键 `gp-clone-v1`）。
直达某个屏：`index.html#demo-today`、`#demo-goal`、`#demo-roadmap`、`#demo-review`。

> 定名"演示"而不是"产品"：它复刻的是外观与判断逻辑，不含原版的日历增删改、学习资源库、
> 多页路由。完整版在 GitHub 仓库里，案例页的「实现与取舍」也写明了这一点。

## 八、发布到网上（三选一）

**A. Netlify Drop（最省事，不用注册也行）**
打开 <https://app.netlify.com/drop>，把整个 `个人主页` 文件夹拖进去，几秒后得到一个网址。

**B. Vercel**
<https://vercel.com> 注册后 → Add New → Project → 直接拖文件夹上传。

**C. GitHub Pages（最正式，网址最像个人主页）**
1. 在 GitHub 新建仓库，把本文件夹所有文件传上去；
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/root` → Save；
3. 一两分钟后访问 `https://你的用户名.github.io/仓库名/`。

> 自定义域名（`www.你的名字.com`）：域名在阿里云 / Namesilo 买，一年几十块，
> 然后在 Netlify 或 Vercel 后台的 Domains 里绑定即可。

## 九、常见问题

**改完没变化？** 浏览器缓存。按 `Ctrl + F5` 强制刷新。

**页面全白 / 内容不出现？** 九成是 `data.js` 里少了一个引号、逗号或括号。
按 `F12` 打开控制台，红色报错会指出第几行。把那一行注释掉再试。

**中文显示成方框？** 本站在微软雅黑 / 苹方 / 思源字体之间自动选，一般不会发生；
如果发生了，说明系统缺中文字体，装一个「思源黑体 / Noto Sans SC」即可。

**想换成另一种风格？** 比如把衬线标题换成无衬线、把网格卡片换成大图整屏滚动，
改 `css/style.css` 里的 `--serif`、`.hero__name` 和 `.works-grid` 三处就够，其余不用动。

**可以直接删掉的部分：** 每个章节底部那条虚线「示例提示」，把 `data.js` 里的
`showEditHints: true` 改成 `false` 就全部隐藏了。
